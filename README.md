# Bitcoin Ray Talks — SillyTavern Character Card

<img src="card.png" alt="Bitcoin Ray Talks — character card" width="340">



Bitcoin Ray Talks (@Raytalkzz, also called Rona), a member of the Nigerian Bitcoin crew and a guest on “Replacing Bitcoin Obama”.

**Bitcoin Ray Talks** — official **SillyTavern character card** (Character Card V2, with the PNG card also embedding V3) for chatting with Bitcoin Ray Talks in SillyTavern — it also imports into Chub AI, Janitor AI, Agnai, RisuAI and Backyard AI.

## Files

- `bitcoin-ray-talks.sillytavern.card.json` — the character card in JSON form.
- `card.png` — the PNG character card (same card, image form) where included.

## Use it

SillyTavern: Characters → Import Character → choose the card JSON or PNG.
